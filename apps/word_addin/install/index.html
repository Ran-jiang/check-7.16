CCiteheck 法律引用核查

在 Word 里一键核查法规与司法案例引用:定位条文、比对权威原文、给出修订建议。按你的系统选择安装方式,约 3 分钟完成。

下载 macOS 安装器
  1. 完全退出 Word(按 Cmd+Q,不只是关闭窗口)。
  2. 双击下载的 install-ccitecheck.command。若 macOS 提示无法打开,右键它并选择“打开”。
  3. 重新打开 Word,在 主页 → 加载项 中找到 CCiteheck 并点击启动。
安装器打不开?手动安装(同样 3 步)
  1. 退出 Word,下载 manifest.xml。
  2. 在 Finder 按 Cmd+Shift+G,粘贴 ~/Library/Containers/com.microsoft.Word/Data/Documents/wef/,把 manifest.xml 复制进去。
  3. 打开 Word → 主页 → 加载项 → CCiteheck。
下载 manifest.xml
  1. 打开 Word,进入 插入 → 获取加载项。
  2. 选择 我的加载项 标签页 → 点击 上传我的加载项。
  3. 选择刚下载的 manifest.xml 并确认,CCiteheck 即出现在主页选项卡。也可以直接粘贴地址 https://cciteheck-api.onrender.com/manifest.xml。
共享文件夹方式(需要管理员权限,适合批量部署)

参考源码仓库 tools/word-installers/windows/ 下的 PowerShell 脚本与说明。

安装后在 Word 中打开任意文档,点击“核查全文”即可。核查时文档内容会上传至部署方服务器处理,请勿核查含敏感个人信息的文书。
